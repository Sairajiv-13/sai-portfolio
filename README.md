# Sai Rajiv — AI systems beyond the demo

This is a **free, static GitHub Pages portfolio**. It does not use a backend, paid API, or resume download.

## Publish with GitHub Pages

1. Create a **public** repository named `sai-portfolio` at https://github.com/new.
2. Upload **everything in this folder to the repository root**: `index.html`, `.nojekyll`, `favicon.png`, `social-preview.png`, and the three `preview-*.svg` files.
3. Commit the upload. Go to **Settings → Pages**. Choose **Deploy from a branch → main → /(root) → Save**.
4. Once deployment succeeds, open https://sairajiv-13.github.io/sai-portfolio/ and test on your phone and desktop.
5. Add the public URL to GitHub and LinkedIn.

## What is included

- Six-stop guided Navi tour with expression states, voice style choices, text dialogue, and motion.
- Conceptual project preview diagrams (clearly labeled). These are **not screenshots of running products**.
- Branded social preview and favicon.
- Responsive layout and reduced-motion handling.
- Project links, experience timeline, contact details, and recruiter view.

## Important

- Navi's speech uses your device's browser voice engine and **may differ across browsers**, or be unavailable. Text and navigation work without audio.
- Social sharing previews are configured for the exact repository name `sai-portfolio`. If you choose a different repository name, change `og:image` and `twitter:image` in `index.html` to your real deployed public image URL.
- The résumé is not included. Public employment history and email are intentionally on the website. Check them before publishing.
- Test external demos because free hosting or third-party services can change.
